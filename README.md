## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build
```

---

## 🛠 Tech Stack
* **Framework:** React 19 + React Router DOM v7
* **Bundler:** Vite (Rolldown)
* **Styling:** Tailwind CSS v3
* **Animations:** Framer Motion v12
* **Icons:** Lucide React
